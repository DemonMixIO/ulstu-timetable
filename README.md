# Расписание УлГТУ

Android-приложение для просмотра расписания УлГТУ с сайта
[`timetable.житков.рф`](https://timetable.житков.рф/).

Проект завайбкоден: версии 1.0–1.5.1 написаны при помощи DeepSeek Harness,
а разработка версии 1.6 и следующих версий продолжается в ChatGPT.

## Готовые функции

- открытие расписания во встроенном окне;
- запоминание последней открытой страницы и позиции прокрутки;
- автоматическое и ручное обновление расписания;
- сохранение расписания для просмотра без сети;
- поиск группы и добавление групп в избранное;
- поиск по предмету, преподавателю и аудитории;
- фильтр по номерам пар;
- скрытие пустых дней и уже прошедших пар;
- выбор своей подгруппы;
- отметка отдельных занятий как необязательных;
- подсветка текущего дня;
- тёмная тема и настройка размера текста;
- режим ПК, вписывание таблицы в экран и открытие ссылок во внешнем браузере;
- виджет «Следующая пара»;
- виджет «Пары на сегодня и завтра»;
- переключение виджета на ближайший учебный день;
- напоминания о начале занятия;
- фоновое обновление расписания и виджетов.

Необязательные занятия, скрытые пары и занятия чужой подгруппы не попадают в
виджеты и напоминания.

## Установка

Готовый APK после сборки находится здесь:

```text
app/build/outputs/apk/debug/app-debug.apk
```

Установка через ADB:

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Минимальная версия Android — 7.0 (API 24).

## Сборка

Нужны JDK 17 и Android SDK с платформой 34.

```bash
./gradlew assembleDebug
```

В Windows:

```bat
gradlew.bat assembleDebug
```

## Изменения

### 1.6

- Пометки необязательных занятий привязаны к конкретному расписанию группы или
  преподавателя и больше не переносятся между разными расписаниями.
- Поиск работает по всем ячейкам, включая первый столбец и страницы преподавателей.
- Добавлен поиск по аббревиатурам названий предметов: например, «дк» находит
  «Деловые коммуникации», а «оит» — «Основы информационных технологий».
- Нажатие на пару открывает контекстное меню: можно добавить домашнее задание,
  выбрать автоматический сброс через неделю и отметить пару как необязательную.
- Домашнее задание отображается прямо в ячейке расписания.

### 1.5.1

- Виджет «Пары на сегодня и завтра» показывает ближайший учебный день после
  окончания занятий.
- Пустые дни пропускаются.
- Переключение можно настроить: после последней пары, в заданное время или никогда.
- Настраиваемое время переключения по умолчанию — 18:00.

### 1.5

- В виджете показывается, сколько времени текущая пара уже идёт и сколько осталось.
- Текущий день выделяется в расписании.

### 1.4

- Исправлены переносы текста в расписании и виджетах.
- Пометки необязательных занятий сохраняются для недель той же чётности.
- Исправлена работа с подгруппами и переносами строк.

### 1.3.1

- Добавлена корректная обработка двух подгрупп в одной ячейке.
- Исправлено распознавание аудиторий с подчёркиванием.
- Исправлен разбор занятий в виджетах.

### 1.3

- Фильтры работают только на страницах с расписанием.
- Добавлен выбор подгруппы.
- Необязательные занятия отмечаются отдельно в каждой ячейке.
- В заголовке показывается название выбранной группы.

### 1.2

- Добавлен поиск по открытой странице расписания.
- Добавлена отметка необязательных занятий.
- Настройки фильтра собраны в отдельном меню.

### 1.1

- Исправлена прокрутка страницы и жест обновления.

### 1.0

- Первая версия приложения: WebView, сохранение страницы, автообновление,
  фильтр, виджеты, напоминания, поиск группы, тёмная тема и офлайн-режим.
